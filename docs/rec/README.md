# rec/ — video explicativo

Este directorio contiene el video asciinema de **Teleasistencia: un botón rojo que abre una videollamada** y el reproductor
que se usa en la página del proyecto.

- `teleasistencia.cast`: grabación original (asciicast v2).
- `teleasistencia.cast.js`: los eventos embebidos para el reproductor inline.
- `player.js` / `player.css`: reproductor reutilizable.

Duración: 3:19. Los fragmentos de código son reales y
corresponden a los archivos y líneas indicados en el video.
